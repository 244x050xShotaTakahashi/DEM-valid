# ジョブスクリプトのカットオフ倍数指定への変更

## 変更対象ファイル

- [job_coulomb_comparison.sh](job_coulomb_comparison.sh)

## 変更内容

### 1. ヘッダーコメントの更新（9-27行目付近）

カットオフの説明を絶対値から倍数指定に変更:

```bash
# 比較ケース:
#   1. クーロン力OFF（ベースライン）
#   --- 固定電荷（DEFAULT_CHARGE使用）---
#   2. カットオフ 50倍半径
#   3. カットオフ 100倍半径
#   4. カットオフ 150倍半径
#   5. カットオフ 200倍半径
#   --- 二峰性電荷分布（charges.dat使用）---
#   6. カットオフ 50倍半径 + bimodal
#   7. カットオフ 100倍半径 + bimodal
#   8. カットオフ 150倍半径 + bimodal
#   9. カットオフ 200倍半径 + bimodal
```

### 2. case文の変更（60-119行目）

`CUTOFF_RADIUS` 変数を `CUTOFF_MULT` に変更し、値を倍数に:

| Task | CASE_NAME | CUTOFF_MULT |

|------|-----------|-------------|

| 1 | no_coulomb | 0 (未使用) |

| 2 | cutoff_50x_fixed | 50 |

| 3 | cutoff_100x_fixed | 100 |

| 4 | cutoff_150x_fixed | 150 |

| 5 | cutoff_200x_fixed | 200 |

| 6 | cutoff_50x_bimodal | 50 |

| 7 | cutoff_100x_bimodal | 100 |

| 8 | cutoff_150x_bimodal | 150 |

| 9 | cutoff_200x_bimodal | 200 |

### 3. sed コマンドの変更（148-151行目付近）

`COULOMB_CUTOFF` の代わりに `COULOMB_CUTOFF_RADIUS_MULT` を設定:

```bash
# 変更前
sed -i "s/^COULOMB_CUTOFF.*/COULOMB_CUTOFF              $CUTOFF_RADIUS/" "$TEMP_INPUT"

# 変更後
sed -i "s/^COULOMB_CUTOFF_RADIUS_MULT.*/COULOMB_CUTOFF_RADIUS_MULT  $CUTOFF_MULT/" "$TEMP_INPUT"
```

### 4. 出力メッセージの更新（177-178行目、278行目）

```bash
# 変更前
echo "Cutoff Radius   : $CUTOFF_RADIUS m"

# 変更後
echo "Cutoff Mult     : ${CUTOFF_MULT}x mean radius"
```
